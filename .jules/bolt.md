## 2024-05-15 - Svelte 5 Object Instantiation\n**Learning:** In Svelte 5, instantiating heavy stateless objects (like `Marked`) directly inside the component block means a new instance is created for every component instance. This can lead to significant memory overhead and slow rendering for long lists of components (like chat messages).\n**Action:** Always extract heavy, stateless objects into a `<script module lang="ts">` block so they are instantiated as singletons. Remember to include `lang="ts"` to prevent type-checking regressions.
